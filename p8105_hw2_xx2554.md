This dataset contains information on each entrance and exit of the NYC
subway system, so each row represents one entrance or exit rather than
one station. The cleaned dataset includes line, station name, station
latitude and longitude, the routes served (`route1` to `route11`),
entry, vending, entrance type, and ADA compliance. To clean the data, I
imported the CSV using a relative path (reading `route8` to `route11` as
character so all route columns have the same type), cleaned variable
names with `janitor::clean_names()`, kept the variables of interest with
`select`, and converted `entry` from `YES`/`NO` to a logical variable
using `case_match`. The resulting dataset has 1868 rows and 19 columns.
These data are not tidy: route served is a single variable, but it is
spread across 11 columns with the route number stored in the column
names, and most of these columns are missing because most stations serve
only a few routes.
